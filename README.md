# ☁️ TeleCloud (تل‌کلود) | مدیریت فایل و فضای ابری تلگرام

پروژه **TeleCloud** یک برنامه وب پیشرفته و مدرن است که پیام‌های ذخیره‌شده تلگرام شما (**Telegram Saved Messages**) را به یک فضای ابری و مدیر فایل قدرتمند مشابه Google Drive تبدیل می‌کند. با این برنامه می‌توانید فایل‌های حجیم خود را بدون اشغال حتی یک بایت فضای دیسک روی سرور (ذخیره‌سازی ۱۰۰٪ ابری در تلگرام)، با بالاترین سرعت آپلود، پخش آنلاین و مدیریت کنید.

---

## 🌟 ویژگی‌های کلیدی (Key Features)

- **📁 مدیریت فایل‌ها به سبک Google Drive:**
  - ساخت پوشه، سازماندهی فایل‌ها، جابجایی، تغییر نام و حذف.
  - نمایش شبکه‌ای (Grid) و لیستی (List) فایل‌ها با پیش‌نمایش هوشمند.
  - قابلیت انتخاب چندتایی (Multi-Select) برای عملیات گروهی (حذف، دانلود، جابجایی).
  - فیلترهای سریع (Quick Filters) برای دسته‌بندی بر اساس نوع فایل (تصاویر، ویدیوها، موزیک‌ها، اسناد، آرشیوها).

- **🎥 پخش‌کننده‌های اختصاصی و پلیرهای داخلی:**
  - **پخش‌کننده ویدیو (Video Player):** پخش روان ویدیوها با قابلیت استریم مستقیم از تلگرام و تنظیمات پخش.
  - **پخش‌کننده صوتی (Audio Player Bar):** نوار پخش موزیک و پادکست در پایین صفحه با قابلیت کنترل کامل (پخش، توقف، تکرار، لیست پخش).
  - **نمایشگر تصاویر (Image Viewer):** گالری و اسلایدر تصاویر با قابلیت زوم و چرخش.
  - **نمایشگر اسناد و متون (Document Viewer):** مشاهده فایل‌های متنی، PDF و کدها به صورت مستقیم.

- **🚀 آپلود پیشرفته بدون ذخیره روی دیسک (Zero Server Disk Storage):**
  - پردازش فایل‌ها به صورت مستقیم در حافظه موقت رم (`Memory Storage`) با استفاده از `multer`.
  - آپلود مستقیم به Saved Messages تلگرام با پشتیبانی از فایل‌های حجیم (تا ۵۰۰ مگابایت و بیشتر).
  - ویجت صف آپلود (Upload Queue Widget) با نمایش وضعیت لحظه‌ای پیشرفت، سرعت و قابلیت لغو.

- **🔐 اتصال امن و احراز هویت تلگرام (Telegram MTProto API):**
  - اتصال امن با استفاده از `API ID` و `API Hash` تلگرام.
  - پشتیبانی از ورود با شماره تلفن، کد تایید (OTP) و رمز عبور Two-Step Verification (تایید دو مرحله‌ای).
  - رمزنگاری پیشرفته جلسات کاربران با الگوریتم **AES-256-GCM**.

- **📊 آمار فضای ذخیره‌سازی (Storage Stats):**
  - نمایش میزان فضای مصرف شده و تفکیک حجم فایل‌ها بر اساس نوع (ویدیو، تصویر، صوت، سند).

- **🌓 پشتیبانی از حالت تاریک و روشن (Dark / Light Theme):**
  - طراحی واکنش‌گرا (Responsive) سازگار با موبایل و دسکتاپ با ناوبری پایین صفحه مخصوص موبایل (`Mobile Bottom Nav`).

## 🛠️ تکنولوژی‌های استفاده‌شده (Tech Stack)

### فرانت‌اند (Frontend):
- **React 19** & **TypeScript**
- **Vite** (بیلر فوق‌العاده سریع)
- **Tailwind CSS v4** (برای استایل‌دهی مدرن و ریسپانسیو)
- **Lucide React** (آیکون‌های مدرن و مینیمال)
- **HLS.js** (پخش استریم مدیا)

### بک‌اند (Backend):
- **Node.js** & **Express**
- **Telegram Client SDK (`telegram` / GramJS)** برای ارتباط با پروتکل MTProto تلگرام
- **Multer** (مدیریت آپلود در حافظه RAM)
- **Crypto** (رمزنگاری امن داده‌های نشست کاربران با AES-256-GCM)
- **Dotenv & Cors & Cookie-Parser**

## ⚙️ پیش‌نیازها و راه‌اندازی (Prerequisites & Installation)

1. **Node.js** (نسخه ۱۸ یا بالاتر)
2. **پکیج منیجر** (`npm` یا `bun`)

### مراحل نصب و اجرا:

1. کلون کردن یا باز کردن پروژه در محیط توسعه.
2. نصب وابستگی‌ها:
   ```bash
   npm install
   ```
3. ساخت فایل محیطی `.env` بر اساس `.env.example`:
   ```env
   PORT=3000
   SESSION_SECRET=your-secure-session-secret
   APP_USERNAME=admin
   APP_PASSWORD=password123
   ```
4. اجرای سرور توسعه و فرانت‌اند به صورت همزمان:
   ```bash
   npm run dev
   ```
5. برنامه روی پورت `3000` در دسترس خواهد بود (`http://localhost:3000`).

## 🔒 امنیت و حریم خصوصی (Security & Privacy)

- **بدون ذخیره‌سازی روی دیسک سرور:** فایل‌های آپلود شده مستقیماً به حافظه موقت (`Memory`) منتقل شده و بدون ذخیره روی هارد سرور به تلگرام ارسال می‌شوند.
- **ارتباط مستقیم با Telegram API:** حساب کاربری شما از طریق پروتکل رسمی MTProto مدیریت شده و هیچ‌گونه دسترسی به کلمات عبور تلگرام شما در سرور ذخیره نمی‌شود.
- **رمزنگاری نشست‌ها:** تمامی توکن‌ها و نشست‌های اتصال با کلید امنیتی `AES-256-GCM` رمزنگاری می‌شوند.
